PERSONAL PROJECT SYNC

Text Structured Drive Sync

A private project utility operated by the account owner to move versioned project files between a Mac, Google Drive and explicitly authorised private GitHub Actions jobs.

个人项目同步工具，用于在账号所有者的 Mac、Google Drive 和经授权的私有 GitHub Actions 任务之间传输项目文件及结果。

What the app does

  • Creates a dedicated project folder and uploads files selected by the owner.
  • Downloads designated inputs for processing and writes new output files.
  • Checks file sizes and checksums to verify transfers.

Limited access

The app requests only the Google Drive drive.file permission. It can work with files it creates or files explicitly made available to it. It does not request access to the entire Drive, Gmail or Google Photos.

Who can use it

This utility is intended for the owner's private project. This website is informational; it has no sign-in form, file upload form or access to project data. Project code, data and credentials are not published here.
