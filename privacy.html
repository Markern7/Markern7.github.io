Privacy Policy

Text Structured Drive Sync · Updated 30 September 2026

Purpose and access

The app transfers project files at the account owner's direction. It requests only https://www.googleapis.com/auth/drive.file. It accesses the contents and metadata of files created by the app or explicitly made available to it, including names, sizes, folder identifiers and checksums.

How information is used

File contents are used for owner-requested storage, download, project processing and result upload. Metadata and checksums support transfer verification and recovery. Google user data is not sold, used for advertising or used for unrelated model training.

Where data and credentials are stored

Project files are kept in the owner's Google Drive and, when requested, on the owner's Mac or in authorised private GitHub Actions jobs. These transfers disclose the selected data to Google and, for cloud jobs, GitHub as infrastructure providers. Credentials are stored separately from project files in protected local files or an explicitly authorised secret store. Credentials are not placed on this public website or in ordinary project archives.

Retention and control

Project snapshots and results remain until the owner removes them using the corresponding storage service. Revoking authorisation prevents future authorised access but does not delete existing copies. The owner can remove the app's access in Google Account connections and can delete project files and credentials from their respective locations.

Security

Transfers to Google and GitHub use HTTPS. Local credential files are restricted to the local user, and cloud credentials are stored in repository secrets when the owner authorises this. No security measure eliminates every risk.

Google API policy

The app's use and transfer of information received from Google APIs will comply with the Google API Services User Data Policy, including its Limited Use requirements.

Contact

The operator is the owner of the Markern7 GitHub account. Configuration questions may be raised in the website issue tracker. Do not post credentials, personal files or private project data in public issues.
